# Dansspel

Een dansspel in de browser. Open `index.html`, druk op de pijltjestoetsen (of de knoppen op het scherm) op het juiste moment en win de beker!

- Dans tegen 3 tegenstanders in een wedstrijd van 60 seconden.
- Plek 1, 2 en 3 krijgen een gouden, zilveren of bronzen beker.
- Speel zo vaak je wilt; je bekers worden bewaard in de browser.
